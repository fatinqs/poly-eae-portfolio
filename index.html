Season of Growth (2024)

Season of Growth (SOG) is my first project that I created for my school module. It is a online book shop website that features the concept of peace and welcoming theme, which is inspired by the colours of the Palestinian flag and library atmosphere. It reflects on the journey of growing into who we are, despite how many times we struggle to get up and progress in life.

I started with a simple concept using the knowledge that I gain in class and eventually improving it through self learning. I was playing around with the code from online resources such as W3Schools and YouTube tutorials using the Adobe Dreamweaver. Through trial and error, I found it stressful to identify the issue, but at the same time, it's quite engaging to create a creative website.

Status: Completed.

Fiverse (2025)

Fiverse is a personal project with a game screen layout concept that I designed for fun using Canva. The name is a combination of my name, "Fatin", and "Universe", which representing my own creative world. It features a retro pixel art style with cute custom characters, console controller layouts, and arcade interface in soft purplish-blue colour theme.

The design is a display of a full game menu with start options, collectible tickets, and signature pixel characters lining up at the bottom. I wanted to blend childhood arcade game vibes with a modern User Interfaces styling to build a nostalgic and cozy digital space.

Status: Paused due to advanced coding and design needed.

Fru.vity (2026)

Fru.vity is a personal project with a concept that I planned for fun. It is a digital dessert world where fruits are used as feelings, featuring motivational quotes, aesthetic vibes, online shop, and dessert recipe lists. I was inspired by a sudden craving for strawberry mochi and mango jelly, which made me want to try out a sweet, soft, and cute design theme.

Originally, the name had no specific meaning, but it eventually evolved into "Fruit and Gravity". I thought it would be interesting if fruits, and sweet treats fell from the sky like a waterfall, creating a lovely world surrounded by sweets that many people would love.

Status: Research and layout planning phase.
